Implementation behavior

Central mapping

getRecipeImage(recipe.id, temperature) owns the Hot/Iced mapping and falls back to /coffee-icon.png for an unknown ID.

Smooth crossfade

RecipeBackdrop mounts both image layers and crossfades opacity over 500 ms with an ease-in-out curve; reduced-motion users get no transition.

Cards and featured

Recipe cards and the Coffee of the Day panel use the active temperature image with dark and category-tint overlays for legibility. Card hover lift and shadow use a 300 ms ease-out transition limited to translate and box-shadow.

Queue and modal

Queue previews default to Iced because they have no selector. The modal header uses both layers and follows its Hot/Iced build controls.

There is no API surface for this feature: no endpoints, auth, persistence, transactions, or backend dependency. The generated files are static frontend assets.

Acceptance and verification

  • 13 of 13 recipes have distinct Hot and Iced generated gradient visuals.
  • Cards, the featured panel, queue previews, and modal use matching temperature assets; queue previews default to Iced.
  • Hot/Iced ingredient behavior remains functional, with a smooth image crossfade on selectable surfaces.
  • Card hover lift and shadow transition smoothly without animating layout properties.
  • Desktop and mobile layouts are readable with no horizontal overflow.
  • npm run lint passed with no findings.
  • npm run build passed through TypeScript and Vite; 26 recipe WebPs are included in the production output.
  • Focused browser QA passed: temperature-layer crossfade, toggle, modal open/close, asset mapping, responsive overflow, and zero console errors or warnings.
  • Card hover QA passed: the first card transitions through an intermediate translate value before settling at the 4 px lift with translate and box-shadow, 300 ms, ease-out.
  • No test script exists in package.json; a full test suite was not available to run.

No required work remains. The original ImageGen PNG outputs remain in the local generated-image archive; only optimized WebPs are shipped under public/recipes/.
