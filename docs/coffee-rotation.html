Rotation contract

The rotation is the library in menu order, filtered to recipes with at least one Hot or Iced build. daysSinceEpoch counts local calendar days from the 2026-09-23 anchor and queueIndexForDate wraps that to a queue position, so the Coffee of the Day changes at local midnight.

Today and next

2026-10-06 Biscoff (13), 2026-10-07 Matcha Caramel (14), 2026-10-08 Cheesecake (0), then the line repeats.

Default build

A recipe's first recommended build that exists, otherwise Hot, otherwise Iced for Iced-only recipes. Not date-based. Users can still switch Hot/Iced by hand.

Iced-only spacing

Gula Melaka, Guava Spark Espresso, and Calamansi Aerocano have no Hot build. src/data/recipes.ts keeps them apart (#06, #10, #13; recipes reordered and renumbered) and a test fails if they become adjacent.

An empty line has queue index 0. The earlier Hot/Iced schedule (alternating by date, flipping each cycle) was removed on 2026-10-06. No API, persistence, transaction, locking, idempotency, or rollback behavior is involved.

User-facing behavior

  • The featured recipe is Biscoff today; the featured panel, list cards and queue open on each recipe's default build.
  • Manual Hot/Iced changes remain available and last for the current view; the home-page control reads Default / Hot / Iced.
  • At local midnight, recipe, queue, position and date label update together.
  • Opening a recipe carries the active card or featured build into the modal; recipes with one available build use that build only.
